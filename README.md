💎 Light Weight Jewellery Store

A modern, responsive Light Weight Jewellery E-Commerce Website built using HTML, CSS, and JavaScript.
This project showcases a beautiful jewellery shopping UI with smooth design, mobile-friendly layout, and deployment on Vercel.

🔗 Live Demo: https://light-weight-buvx.vercel.app/

✨ Features
🛍️ Elegant jewellery product UI (lightweight collection)
📱 Fully responsive design (mobile + desktop)
⚡ Fast loading static website
🎨 Modern UI with clean animations
🧭 Easy navigation (Home, Products, Contact sections)
💬 WhatsApp / Contact integration (if added)
🚀 Deployed on Vercel for instant access
🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla)
Vercel (Deployment)

🚀 How to Run Locally
Clone the repository
git clone https://github.com/your-username/light-weight-jewellery.git
Open project folder
cd light-weight-jewellery
Run index.html in your browser
double click index.html
🌐 Deployment (Vercel)

To deploy on Vercel:

Push project to GitHub
Go to https://vercel.com/
Import GitHub repository
Click Deploy
