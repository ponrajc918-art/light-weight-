<img width="1871" height="908" alt="image" src="https://github.com/user-attachments/assets/df3bcf9c-dabb-4dcd-ab13-743809536a60" /># 💎 Light Weight Jewellery Store

A modern, responsive jewellery website built using HTML, CSS, and JavaScript.  
This project showcases a lightweight jewellery shopping UI with clean design and smooth user experience.

🔗 Live Demo: https://light-weight-buvx.vercel.app/

---

## ✨ Features

- Responsive design (mobile + desktop)
- Clean and modern UI
- Fast loading static website
- Product showcase layout
- Simple navigation system
- Deployed using Vercel

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Vercel (Deployment)

---

## 🚀 Getting Started

### 1. Clone the repository

### 2. Move into the project folder
cd light-weight-je
### 3. Run the project
Open `index.html` in your browser

---

## 🌐 Deployment

### Deploy on Vercel
1. Push code to GitHub  
2. Go to https://vercel.com  
3. Import repository  
4. Click Deploy
